📞 NEXT STEPS - TO GET STARTED
════════════════════════════════════════════════════════════════════════════════

BEFORE RUNNING THE BOT:

1. ✋ COPY & EDIT .env FILE
   $ cp .env.example .env
   $ nano .env
   
   Add your credentials:
   • ANGEL_ONE_API_KEY = [your Angel One API key]
   • ANGEL_ONE_AUTH_TOKEN = [your auth token]
   • ANGEL_ONE_CLIENT_CODE = [your client code]
   • DHAN_API_KEY = [your Dhan API key]
   • DHAN_CLIENT_ID = [your Dhan client ID]

2. 🔒 ENSURE .env HAS CORRECT PERMISSIONS
   $ chmod 600 .env
   $ ls -la .env  # Should show -rw------- permissions

3. 📦 INSTALL PYTHON PACKAGES
   $ pip install -r requirements.txt

4. ✅ VERIFY SETUP
   $ python3 quickstart.py  # Optional interactive setup


RUN THE BOT:

5. 📄 PAPER TRADING (Recommended first)
   $ python3 trading_bot.py
   
   Expected output:
   - ✅ Angel One authentication successful
   - 📄 PAPER TRADING MODE ACTIVE
   - 📊 Fetching real-time SILVER futures data...
   - Watch for signals & simulated trades

6. 📊 MONITOR LIVE
   In another terminal:
   $ tail -f trading_bot.log

7. 📈 AFTER SESSION
   Check results:
   $ cat session_trades.json | python3 -m json.tool


ADVANCED (AFTER TESTING):

8. 💰 SWITCH TO LIVE TRADING (Only after 1-2 weeks of successful paper trading)
   Edit .env: PAPER_TRADE_ENABLED=false
   Then run: python3 trading_bot.py

9. 🔄 RETRAIN MODEL (Quarterly or when signal quality drops)
   $ python3 1_mcx_scraper.py --days 365
   $ python3 feature_engineering.py
   $ python3 ml_training.py

Q: Is this guaranteed to make money?
A: No. Past performance ≠ future results. Test thoroughly first.

Q: Can I run this on my laptop?
A: Yes, but VPS is recommended for 24/7 operation.

Q: What if the bot crashes?
A: All trades are saved to session_trades.json. Restart bot.

Q: Can I modify the trading parameters?
A: Yes, edit .env file to change stop-loss, profit target, etc.

Q: How often should I retrain the model?
A: Every 3-6 months or when signal quality drops.

Q: Is paper trading truly risk-free?
A: Yes, in paper mode, no real money is used. Perfect for testing.

Q: What's the minimum capital needed?
A: Dhan typically requires ₹50,000+ for trading.

Q: Can I run multiple bots simultaneously?
A: Not recommended initially. Start with one bot, one symbol.
