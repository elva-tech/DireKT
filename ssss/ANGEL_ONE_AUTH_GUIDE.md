# 🔐 ANGEL ONE SmartAPI - MANUAL AUTHENTICATION GUIDE

## Problem
The automated authentication is failing due to API endpoint restrictions (405 errors).

## Solution: Manual Authentication

Angel One SmartAPI tokens expire, so you need to generate them periodically. Follow these steps:

### Method 1: Using Angel One Web Panel (Recommended)

1. **Log in to Angel One:**
   - Go to https://www.angelbroking.com
   - Log in with your credentials

2. **Generate API Token:**
   - Navigate to: **Settings → API Management**
   - Look for "SmartAPI" section
   - Click "Generate New Token" or "Refresh Token"
   - You'll get:
     - `jwtToken` (also called Authorization Token or Auth Token)
     - `feedToken` (also called Feed Token)

3. **Copy Your Tokens:**
   - Copy the `jwtToken` value
   - Copy the `feedToken` value

4. **Update .env File:**
   ```bash
   nano .env
   ```
   
   Add these lines:
   ```env
   ANGEL_ONE_AUTH_TOKEN=<your_jwtToken_here>
   ANGEL_ONE_FEED_TOKEN=<your_feedToken_here>
   ```

5. **Save and Exit:**
   - Press `Ctrl+X` then `Y` then `Enter`

---

### Method 2: Using cURL (Advanced)

If you want to automate token generation, use this cURL command:

```bash
curl -X POST https://smartapi.angelbroking.com/rest/secure/login \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "X-UserType: USER" \
  -d '{
    "clientcode": "YOUR_CLIENT_ID",
    "password": "YOUR_PASSWORD",
    "totp": "YOUR_TOTP_HERE"
  }'
```

Replace with your actual values from .env

---

### Method 3: Using Python Script

Run the provided authentication helper:

```bash
python3 auth_helper.py
```

**Note:** This may fail if API endpoints are restricted. In that case, use Method 1.

## Token Expiration

SmartAPI tokens expire after **120 minutes**.

The trading bot will:
1. ✅ Auto-refresh tokens when expired (if auto-auth works)
2. ❌ Fail with 401 error if token expires and auto-refresh fails

**Solution:** Re-generate tokens before running bot:

```bash
# Manual refresh every 1-2 hours
nano .env  # Update ANGEL_ONE_AUTH_TOKEN with new value from web panel
```

## Verification: Check If Tokens Work

After updating `.env` with your auth token:

```bash
python3 -c "
import requests
import os
from dotenv import load_dotenv

load_dotenv()

token = os.getenv('ANGEL_ONE_AUTH_TOKEN')
api_key = os.getenv('ANGEL_ONE_API_KEY')

headers = {
    'Authorization': f'Bearer {token}',
    'Content-Type': 'application/json',
    'X-UserType': 'USER'
}

payload = {
    'mode': 'LTP',
    'exchangeTokens': {'MCX': {'SILVER': ['all']}}
}

response = requests.post(
    'https://smartapi.angelbroking.com/rest/secure/quote',
    json=payload,
    headers=headers,
    timeout=10
)

if response.status_code == 200:
    print('✅ Token is valid!')
    print(response.json())
else:
    print(f'❌ Token invalid: {response.status_code}')
    print(response.text)
"
```

## Troubleshooting

| Error | Cause | Solution |
|-------|-------|----------|
| 401 Unauthorized | Token expired or invalid | Generate new token via web panel |
| 405 Method Not Allowed | Endpoint blocked | API endpoint restrictions, use web panel |
| 403 Forbidden | API key not enabled | Enable SmartAPI from Angel One settings |
| Connection timeout | Network issue | Check internet, try VPN |
